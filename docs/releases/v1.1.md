# coop-crew v1.1

Easier to start, easier to watch, the same crew. Nothing about what the crew does, or any safety rule, changed: it
still submits and sends nothing until the student approves that exact item.

## Install

```
curl -fsSL https://claude.ai/install.sh | bash      # Claude Code, if you don't have it; then run `claude` once to sign in
git clone https://github.com/dudailia/coop-crew && cd coop-crew && ./install.sh && claude
```

Then `/demo --offline` (a made-up sample student, a few seconds) and `/setup` to make it yours. Or click **Use this
template** on the repository page to start your own copy.

## What changed since 1.0

- **A smooth demo video and GIF.** Recorded frame by frame by a scripted browser: one constant scroll speed, no jumps,
  no repeated frames, captions that fade, scenes that dip through white. The attached `demo.mp4` is 1280x720 at 30 fps
  (60 s); the README GIF is 960x540 at 15 fps (14 s), a seamless loop under 8 MB.
- **A new README**: banner, badges, a three-step quickstart, a Mermaid diagram of the agents, an FAQ, and "Using this
  at another school" for students without NUworks.
- **CI on every push**: `./install.sh`, then the tests on Python 3.9 and 3.13, the NUworks server tests and the
  personal-data scan.
- **Template repository and Discussions** for questions.
- `/setup` accepts a summer cycle, for a summer internship at another school. From the new-student test: it explains
  the two NUworks routes correctly, and writes email regions only for the cities the student names.
- The repo's Claude Code settings turn off the co-author and PR attribution lines, and earlier commit messages were
  rewritten without them. Authors, dates and files are unchanged; the hashes changed, and `v1.0` points to the rewritten
  v1.0 commit.

The full list is in [CHANGELOG.md](https://github.com/dudailia/coop-crew/blob/main/CHANGELOG.md).

- The personal-data scan and gitleaks over the tree and the full history: no findings.
- Every frame of the video and GIF checked by script for even motion (1 px per frame in the video, 3 px in the GIF,
  no repeated frames, a jump-free loop) and by OCR for company names: only the made-up companies appear.
- The new-student test from a fresh clone: an empty home folder, the README followed word for word, then `/demo

  `/crew-resume` in Claude Code's default permission mode. Two rounds each needed one `/setup` wording fix; the
  third needed none.
