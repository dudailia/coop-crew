# coop-crew v1.0

A crew of Claude Code agents that works one student's co-op and internship search overnight. It finds roles on company
job boards and in the student's NUworks job-alert emails, researches each company, and prepares a one-page resume, the
form answers and any outreach email. The student reads one page in the morning and approves what is right. **Nothing is
submitted or sent until the student approves that exact item.**

## Install

```
git clone https://github.com/dudailia/coop-crew && cd coop-crew && ./install.sh && claude
```

Then `/demo` (a made-up sample student, about five minutes; `/demo --offline` needs no network) and `/setup` to make it
yours. macOS, Linux, or Windows with WSL; Python 3.9+, Node.js 18+ (22+ for the form filler), git, and Claude Code on a
paid Claude plan. No API keys. New to Claude Code? The README's quickstart starts from zero.

## What is in 1.0

- Twelve agents (`.claude/agents/`), six skills, nine commands: `/setup`, `/run`, `/today`, `/approve`, `/skip`,
  `/stop`, `/crew-resume`, `/demo`, `/crew-doctor`.
- TODAY.html: questions for the student, and review packs with the company brief, the one-page resume, the answers,
  soft flags and a field log of every form field.
- Safety in code: prepare mode by default, approvals only from the student, a guard hook on every tool call, a kill
  switch, daily caps, and a checker that fails any claim not in the student's `facts.md`.
- NUworks within the rules: by default only the student's own job-alert emails and saved postings. The job-alert reader
  was checked against real NUworks alerts: it follows the Outlook Safe Links and job-redirect links that university mail
  uses. The read-only browser reader ships off, behind a notice quoting Symplicity's terms of use and a typed
  acknowledgement (see `mcp/nuworks/APPROVAL.md`).
- Northeastern rules: co-op dates and cycle, applying in NUworks yourself, the self-developed co-op banned-list check,
  work authorization word for word, and no drafting of answers that must be written without AI.
- Our own anti-slop catalogue (`.claude/skills/anti-slop/catalogue.md`). Every third-party text in the repo has a
  license that allows redistribution (`THIRD_PARTY.md`).
- Talk materials in `docs/talk/`: an offline slide deck, the demo script, and a note for attendees.
- CONTRIBUTING.md, SECURITY.md (private reporting) and issue templates.
